# Kyle Stewart — Portfolio

A Vite + React portfolio with case studies from Google Ads and Intuit. Originally generated by [Magic Patterns](https://magicpatterns.com).

## Getting Started

1. **Install dependencies:** `npm install`
2. **Start dev server:** `npm run dev` — app runs at [http://localhost:5173](http://localhost:5173)
3. **Build for production:** `npm run build`
4. **Preview production build:** `npm run preview`
5. **Lint:** `npm run lint`

## Project Structure

- `src/App.tsx` — Route definitions
- `src/pages/` — Home and case study pages (Expert Scheduling, Conversion Goal Updates, Flexible Lift Confidence, Measurement Setup)
- `src/components/` — Header, Footer, CaseStudyLayout
- `src/index.css` — Global styles, Tailwind, fonts
